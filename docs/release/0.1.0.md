# Diffloom 0.1.0 release record

The feature roadmap originally staged through 1.0 is implemented in one 0.1.0 release. The version is intentionally kept below 1.0 because public API stabilization remains an explicit future compatibility gate.

## Included

- Diff engine.
- Matching engine.
- Patch engine.
- CLI.
- C ABI.
- Compatibility contract.
- Tests and regression corpus.
- Fuzz targets.
- Security controls and documentation.
- Cross-platform CI.
- Release verification workflow.

## Release verification

    cargo fmt --all -- --check
    cargo test --workspace
    cargo clippy --workspace --all-targets -- -D warnings
    cargo build --workspace
    cargo build --release --workspace

The immutable release identifier is intended to be the git commit SHA plus the v0.1.0 tag.
